# Libri / Books

Do you like like reading? So learn some Italian vocabulary to describe books!

(nouns)

l'autore / l'autrice [author]

il protagonista [main character]

lo scrittore [writer]

il critico [critic]

il lettore [reader]

il fumetto [comic strip / cartoon]

la narrativa [narrative]

il romanzo [novel] FALSE FRIEND ALERT!(a romantic novel in Italian is called &#8216;un romanzo rosa')

il racconto [story]

la poesia [poetry]

il tascabile [pocketbook]

la casa editrice [publishing house]

la trama [plot]

la recensione [review]

il saggio [essay / sage]

(adjectives)

avvincente [fascinating]

sdolcinato [mawkish / soppy]

appassionante [exciting]

osceno [obscene]

sentimentale [sentimental]

banale [banal]

divertente [funny]

emozionante [moving]

geniale [brilliant] FALSE FRIEND ALERT! (&#8216;Geniale' in Italian is not &#8216;genial' in English)

intelligente [intelligent]

leggero [light]

noioso [boring]

profondo [deep / profound]

ridicolo [ridiculous]

romantico [romantic]

superficiale [superficial]

volgare [vulgar]

satirico [satirical]

triste [sad]

vivace [lively]
